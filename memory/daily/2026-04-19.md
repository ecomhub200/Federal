### Session (12:20) - Wiki Deployment & Initial Seeding

**Context:** User asked Claude to deploy the Karpathy-style LLM wiki
(https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) and keep
CLAUDE.md in sync. The wiki scaffolding (`memory/AGENTS.md`, hooks, scripts)
already existed but runtime directories were missing, and the project's root
CLAUDE.md had no reference to the wiki system.

**Key Exchanges:**
- Confirmed `.claude/settings.json` already wires SessionStart / SessionEnd /
  PreCompact to `memory/hooks/*.py`.
- SessionStart hook was verified to emit the expected
  `hookSpecificOutput.additionalContext` JSON with the (empty) index.
- User then asked to start seeding the wiki. Decided to lift structured
  knowledge out of `CLAUDE.md` rather than wait for organic conversations,
  because CLAUDE.md already contains canonical, encyclopedia-ready material.

**Decisions Made:**
- **Wiki lives in `memory/`**, hooks fire automatically inside Claude Code,
  compile/query/lint run via `uv` against `memory/pyproject.toml`.
- **Seed strategy**: extract atomic concepts from CLAUDE.md (state
  management, EPDO weights, DOT-neutral naming, modular architecture) as the
  first wave. Future daily logs will grow the graph organically.
- **Branch**: all wiki work lands on `claude/deploy-wiki-update-docs-TPKvS`,
  no direct pushes to main (per CLAUDE.md rule #1).
- **Naming**: lowercase-kebab filenames, Obsidian-style `[[wikilinks]]`
  relative to `knowledge/`, YAML frontmatter mandatory.

**Lessons Learned:**
- `memory/.gitignore` tracks `daily/` and `knowledge/` intentionally — they
  ARE the knowledge base and must be versioned.
- `reports/` is gitignored; `lint.py` regenerates it.
- The SessionStart hook truncates at 20,000 chars; keep `index.md` compact
  (summaries, not full articles) so it stays under budget as the KB grows.
- `scripts/config.py` names the canonical sub-dirs: `concepts/`,
  `connections/`, `qa/`. Any new article directory must be added here and in
  `utils.list_wiki_articles()`.
